# Модуль 09. Лабораторная работа / СРСП: Inventory Manager на Golang

Лабораторная работа (СРСП) по дисциплине «Разработка веб-сервисов» (CSE5032).  
Кафедра Программной инженерии, Институт Автоматики и информационных технологий.

---

## 🎯 Цель работы
Изучить базовые конструкции языка Go:
- Объявление структур `Item` и коллекций в памяти;
- Реализация методов работы со срезом `[]Item`;
- Обновление состояния элементов через указатели и срезы;
- Агрегационные вычисления общей стоимости запасов и остатков;
- Алгоритмы фильтрации по категориям и контроль критического остатка (`Low Stock`).
