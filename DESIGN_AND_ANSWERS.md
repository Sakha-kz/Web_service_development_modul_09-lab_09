# Отчёт и результаты работы: Модуль 09 (Лабораторная работа / СРСП)

## 📌 Архитектура и функционал Inventory Manager
1. **Модель Item:**
   ```go
   type Item struct {
       ID       int
       Name     string
       Category string
       Price    float64
       Quantity int
   }
   ```
2. **Алгоритм обновления количества (UpdateQuantity):**
   Обход среза по индексам `for i := range inv.items` позволяет напрямую модифицировать поля структуры в памяти без копирования:
   ```go
   inv.items[i].Quantity = newQty
   ```
3. **Контроль дефицита товаров (Low Stock Threshold):**
   Пользователь может задать пороговое число (по умолчанию 5). Функция `FindLowStock` фильтрует срез и выводит предупреждения о товарах, требующих срочной закупки.
